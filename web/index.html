Manual curve fit (the four sliders)

Delayed mode: t0 is when the closest-approach sound reaches you (CPA time + slant distance / 343 m/s); the curve is asymmetric because sound emitted while approaching arrives compressed in time. Position mode ignores the delay (symmetric curve, t0 = geometric CPA) — that is the plain measurement-tool curve. All searches use the delayed times.
